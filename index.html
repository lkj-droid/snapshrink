Frequently asked questions

Are my images uploaded anywhere?

No. SnapShrink is a static page. All decoding, resizing and re-encoding happens in your browser using the HTML5 Canvas API, and the ZIP archive is assembled in JavaScript on your device. You can open your browser's network panel and watch: no request carries your image data.

Which formats can I convert to and from?

Input: PNG, JPEG, WebP, GIF and BMP. Output: WebP, JPEG and PNG. Animated GIFs and animated WebP files are converted using their first frame, because canvas encoding produces still images.

How much smaller will my files get?

It depends on the source. A screenshot saved as PNG typically drops 60–90% when converted to WebP at 80% quality. A JPEG that is already compressed may only shrink 20–40%, or even grow if you pick a very high quality — SnapShrink flags that per image so you can lower the quality or keep the original.

Does the quality slider affect PNG?

No. PNG is a lossless format, so the slider is disabled when PNG is selected. Its gains come from resizing and from removing metadata, which canvas re-encoding always does.

What happens to EXIF data, GPS location and other metadata?

SnapShrink reads it first and removes it on conversion. As soon as a file is added, the card reports how many EXIF tags it contains, the camera and date, and whether GPS coordinates are embedded — expand the note to see the values. Re-encoding through canvas keeps only the pixels, so the converted file has none of it, and SnapShrink checks the result to confirm. The trade-off is that camera settings and rotation tags are not carried over; SnapShrink applies the correct orientation to the pixels before saving.

Can I check a photo for GPS data before I share it?

Yes. Pick the file and its header is parsed in your browser, before anything is converted: the card shows the EXIF tag count and a GPS location badge, and the details list the coordinates, camera model and capture date inside the file. Convert it and the same check runs again on the output, so you can see the tags drop to zero instead of taking it on trust.

Which platform sizes are built in?

YouTube thumbnail 1280×720, Instagram post 1080×1080, Instagram story and Reel cover 1080×1920, X post 1600×900, link preview (Open Graph) 1200×630, Pinterest pin 1000×1500 and app icon 512×512. Each one crops to fill or fits the image inside with a background colour, and anything else can be typed into Custom size.

Is there a file size or count limit?

There is no server limit, but your device's memory is the real ceiling. 40 images per batch is a comfortable number on a phone; very large images (above roughly 40 megapixels) may be rejected by the browser's canvas.

Can it convert HEIC photos from an iPhone?

Not directly — browsers do not decode HEIC in canvas. On iOS, choose “Most Compatible” in Settings → Camera → Formats, or export the photo as JPEG from the Photos app first.

Do I need to install anything or create an account?

No. The tool is free, needs no sign-up, adds no watermark, and can be saved for offline use (in Chrome: menu → Cast, save and share → Install page as app).
